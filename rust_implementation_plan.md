# Реализация развёртки 3D модели в 2D SVG

## Алгоритм развёртки

Для реализации MVP (Minimum Viable Product) развёртки 3D модели в 2D SVG был выбран следующий подход:

1. **Простая проекция**: Используется ортографическая проекция на плоскость XY
2. **Полигональное представление**: Каждая грань 3D модели проецируется как 2D полигон
3. **SVG генерация**: Создаётся SVG файл с полигонами всех граней

### Преимущества подхода:
- Простота реализации
- Быстрое выполнение
- Не требует сложных вычислений разрывов швов
- Подходит для демонстрации функциональности

### Ограничения:
- Нет оптимизации расположения деталей
- Нет разрывов швов для корректной развёртки
- Нет учета толщины материала

## Структура реализации

### 1. Python скрипт (src-tauri/addon_server.py)

Файл содержит функцию `unfold_mesh_to_svg`, которая:
- Загружает 3D модель из OBJ файла с помощью библиотеки `trimesh`
- Применяет простую проекцию на плоскость XY
- Генерирует SVG с полигонами всех граней
- Возвращает JSON ответ со статусом операции

### 2. Rust интеграция (src-tauri/src/commands.rs)

Добавлена команда `unfold_3d_model`, которая:
- Принимает путь к 3D модели (OBJ файл)
- Вызывает Python скрипт через `tokio::process::Command`
- Передаёт пути к временным файлам
- Читает сгенерированный SVG и возвращает его содержимое

### 3. Store (src/stores/projectStore.ts)

Создано хранилище Pinia с функциональностью:
- Хранение состояния 3D модели
- Вызов команды развёртки через Tauri invoke
- Управление состоянием загрузки и ошибками

### 4. Компоненты UI

- **SheetPreview.vue**: Отображает SVG развёртки
- **UnfoldButton.vue**: Кнопка для запуска развёртки
- **ModelViewer3D.vue**: 3D вьювер с возможностью вызова развёртки
