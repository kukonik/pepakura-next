## 1. Обзор проекта

Pepakura Next — это десктопное приложение для работы с 3D-моделями и их развёртками (papercraft unfolding), интегрированное с AI-ассистентом. Проект использует современный стек технологий:

- **Фронтенд:** Vue 3 Composition API, TypeScript, Pinia для state management
- **Бэкенд:** Rust, Tauri framework для десктопных приложений
- **AI интеграция:** Ollama как локальный LLM сервер, REST API на порту 11434
- **3D обработка:** Генерация мешей, развёртка (unfolding), анализ искажений
- **Сохранение состояния:** Dexie для IndexedDB, автосохранение сессий
- **Горячие клавиши:** Глобальная система горячих клавиш
- **Командная палитра:** UI для быстрого доступа к командам

## 4. Проблемы и ограничения

### 4.1 Критические проблемы

1. **Отсутствие директории `ui-desktop`**
   - **Описание:** Скрипты `package.json` ссылаются на `ui-desktop`, но директория отсутствует
   - **Влияние:** Невозможно запустить приложение через `npm run dev`
   - **Решение:** Обновить скрипты или восстановить структуру monorepo

2. **AI сервис не интегрирован с Ollama**
   - **Описание:** `ai_service.rs` содержит пустую строку `ollama_url`
   - **Влияние:** Генерация 3D моделей через AI не работает
   - **Решение:** Настроить подключение к Ollama или удалить неработающий функционал

### 4.2 Потенциальные проблемы

1. **Несоответствие типов Mesh**
   - **Описание:** `MeshData` (TypeScript) может не полностью соответствовать `Mesh` (Rust)
   - **Влияние:** Ошибки при передаче данных в команды AI
   - **Решение:** Проверить сериализацию/десериализацию

2. **Отсутствие обработки ошибок в некоторых Tauri командах**
   - **Описание:** Не все команды имеют полноценную обработку ошибок
   - **Влияние:** Приложение может крашиться при неожиданных данных
   - **Решение:** Добавить обработку ошибок и валидацию входных данных

3. **Производительность при работе со сложными 3D-моделями**
   - **Описание:** Нет тестов на больших моделях
   - **Влияние:** Возможны лаги и зависания
   - **Решение:** Оптимизация алгоритмов, добавление прогресс-баров

### 4.3 Архитектурные ограничения

1. **Монолитная структура `commands.rs`**
   - **Описание:** Файл содержит 926 строк, что затрудняет поддержку
   - **Решение:** Разделить на модули (import/export, unfold, nest, etc.)

2. **Отсутствие unit-тестов**
   - **Описание:** Нет тестов для Vue компонентов и Rust команд
   - **Решение:** Добавить тестовый фреймворк (Vitest, Rust tests)
