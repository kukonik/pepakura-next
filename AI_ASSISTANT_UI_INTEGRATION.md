# AI Assistant Integration

## Обзор
Интеграция AI Assistant в Vue UI Pepakura Next предоставляет пользователям возможность взаимодействовать с AI для получения рекомендаций по развёртке, анализа моделей и ответов на вопросы.

## Архитектура

```
ui-desktop/src/
├── stores/aiStore.ts                 # Состояние AI (Tauri invoke)
├── components/ai/
│   ├── AiAssistantPanel.vue         # Основная панель AI
│   └── AiMessageList.vue            # Список сообщений чата
├── pages/AiAssistantPage.vue        # Страница роута /ai/assistant
└── i18n.ts                          # Конфигурация локализации
```

## Возможности

### 1. Индикатор статуса Ollama
- ✅ Проверка доступности Ollama при загрузке
- ✅ Авто-поллинг каждые 30 секунд
- ✅ Ручное обновление статуса
- ✅ Визуальные статусы: Online (зелёный), Offline (красный), Checking (жёлтый)

### 2. AI Чат
- ✅ Отправка сообщений в AI
- ✅ История сообщений с временными метками
- ✅ Markdown форматирование (жирный, курсив, код, списки)
- ✅ Typing indicator при ожидании ответа
- ✅ Очистка истории чата

### 3. AI Анализ модели
- ✅ Проверка наличия загруженной модели
- ✅ Запуск анализа через `ai_get_unfold_advice`
- ✅ Отображение результатов:
  - Рекомендуемый алгоритм
  - Макс. итераций
  - Допуск
  - Советы (список)
  - Возможные проблемы (список)

### 4. Обработка ошибок
- ✅ Баннер ошибок в чате
- ✅ Сообщения об ошибках с локализацией
- ✅ Graceful degradation при недоступности Ollama

## Tauri команды

| Команда | Описание | Параметры |
|---------|----------|-----------|
| `ai_check_status` | Проверка статуса Ollama | - |
| `ai_chat` | Отправка сообщения в чат | `message: string`, `history: ChatMessage[]` |
| `ai_get_unfold_advice` | Анализ модели | `mesh: Mesh` |
| `ai_analyze_distortion` | Анализ искажений | `mesh: Mesh`, `unfolded: UnfoldResult` |

## Тестирование

### Проверка работы компонента:

1. **Запуск приложения:**
   ```bash
   cd platform/desktop/ui-desktop
   npm run dev
   ```

2. **Навигация:**
   - Откройте приложение
   - Нажмите "AI Ассистент" в боковой панели
   - Проверьте индикатор статуса (должен стать зелёным если Ollama запущен)

3. **Тест чата:**
   - Введите сообщение в поле ввода
   - Нажмите "Отправить"
   - Проверьте появление ответа от AI

4. **Тест анализа:**
   - Загрузите 3D модель
   - Перейдите на вкладку "Результаты анализа"
   - Нажмите "AI Анализ модели"
   - Проверьте появление результатов

### Тест обработки ошибок:

1. Остановите Ollama сервис
2. Проверьте появление красного индикатора "Ollama не доступен"
3. Попробуйте отправить сообщение - должна появиться ошибка

## Известные ограничения

- ⚠️ AI доступен только для Desktop версии (WASM без AI)
- ⚠️ Требуется запущенный Ollama на `localhost:11434`
- ⚠️ Поддерживаемые модели: llama3 и совместимые

## Troubleshooting

### "Ollama не доступен"
- Убедитесь, что Ollama запущен: `ollama serve`
- Проверьте порт: `http://localhost:11434`
- Установите модель: `ollama pull llama3`

### Ошибка компиляции "vue-i18n not found"
```bash
pnpm install
# или
npm install vue-i18n@9
```

### Пустые результаты анализа
- Убедитесь, что 3D модель загружена
- Проверьте консоль на ошибки
- Проверьте логи Tauri в консоли Rust
