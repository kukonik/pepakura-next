# Модульные расширения (Addons)

Аддоны позволяют расширять функциональность Pepakura Next без модификации ядра. Они могут быть реализованы на любом языке (Rust, Python, JavaScript) и взаимодействовать с ядром через IPC или прямые вызовы (в случае WASM).

## Типы аддонов

1. **Внутренние аддоны** (компилируются в ядро) — Rust-модули, реализующие определённые трейты.
2. **Внешние аддоны** (отдельные процессы) — Python-скрипты, CLI-утилиты, которые общаются через JSON-RPC (как `addon_server.py`).
3. **WASM-аддоны** — загружаемые во время выполнения модули, которые могут выполняться в изолированной среде.

## Структура аддона

Каждый аддон должен предоставлять:

- `manifest.json` — метаданные (название, версия, поддерживаемые операции).
- Основной код (исполняемый файл или библиотека).
- (Опционально) Конфигурацию для интеграции с UI.

## Пример внешнего аддона (Python)

См. `addon_server.py` — простой сервер, который обрабатывает запросы:

```json
{
  "tool": "model_tools",
  "op": "analyze_model",
  "payload": {
    "path": "/path/to/model.obj",
    "format": "auto"
  }
}
```

Ответ:

```json
{
  "ok": true,
  "result": {
    "format": "obj",
    "faces": 123,
    "vertices": 456,
    "parts": 1
  }
}
```

## Интеграция с ядром

Ядро предоставляет точку расширения `AddonManager`, который может загружать аддоны и делегировать операции. В текущей реализации используется вызов внешнего процесса через `std::process`.

## Создание нового аддона

1. Создайте папку в `addons/your_addon/`.
2. Напишите `manifest.json`.
3. Реализуйте обработчик запросов.
4. Протестируйте через вызов из ядра или UI.

## Пример manifest.json

```json
{
  "name": "model_analyzer",
  "version": "1.0.0",
  "description": "Analyzes 3D model files",
  "author": "Your Name",
  "entry_point": "addon_server.py",
  "supported_operations": [
    "analyze_model",
    "unfold_model"
  ]
}
```

## План развития

- Стандартизировать протокол обмена (JSON-RPC).
- Добавить поддержку горячей перезагрузки аддонов.
- Интегрировать аддоны в UI (дополнительные вкладки, кнопки).
- Создать реестр аддонов для обмена.
