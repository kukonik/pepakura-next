# Command Palette (Палитра команд)

## Обзор

Command Palette предоставляет быстрый доступ ко всем командам приложения через клавиатуру. Это модальное окно с поиском, которое позволяет опытным пользователям выполнять действия без использования мыши.

## Основные возможности

- **Быстрый вызов**: `Ctrl+K` (Windows/Linux) или `Cmd+K` (macOS)
- **Fuzzy search**: Нечеткий поиск по названию, описанию и ключевым словам
- **Горячие клавиши**: Отображение назначенных комбинаций клавиш
- **Категории**: Группировка команд по категориям
- **Иконки**: Визуальные индикаторы для быстрой идентификации

## Использование

### Открытие палитры команд

1. **Клавиатура**: Нажмите `Ctrl+K` (или `Cmd+K` на Mac)
2. **Мышь**: Нажмите кнопку "Команды" в заголовке приложения
3. **Меню**: В будущих версиях будет доступно через главное меню

### Навигация в палитре

- **Поиск**: Начните вводить название команды
- **Стрелки**: `↑` и `↓` для навигации по списку
- **Выбор**: `Enter` для выполнения выбранной команды
- **Отмена**: `Esc` для закрытия палитры
- **Tab**: Циклическое переключение между командами

### Примеры поиска

- `export pdf` → "Export PDF"
- `развертка` → "Unfold Model"
- `ai` → "Generate AI Model"
- `настройки язык` → "Change Language"

## Доступные команды

### Файловые операции (`Ctrl+K` → введите "file")
- **New Project** (`Ctrl+N`) - Создать новый проект
- **Open Project** (`Ctrl+O`) - Открыть существующий проект
- **Save Project** (`Ctrl+S`) - Сохранить текущий проект
- **Export PDF** (`Ctrl+Shift+P`) - Экспортировать развертки в PDF
- **Export SVG** (`Ctrl+Shift+S`) - Экспортировать развертки в SVG

### Редактирование (`Ctrl+K` → введите "edit")
- **Undo** (`Ctrl+Z`) - Отменить последнее действие
- **Redo** (`Ctrl+Y`) - Повторить отмененное действие
- **Flip Part** (`F`) - Перевернуть выбранную деталь
- **Rotate Part** (`R`) - Повернуть выбранную деталь

### Вид (`Ctrl+K` → введите "view")
- **Toggle Wireframe** (`W`) - Переключить режим каркаса
- **Toggle Textures** (`T`) - Включить/выключить текстуры

### Инструменты (`Ctrl+K` → введите "tools")
- **Unfold Model** (`U`) - Развернуть 3D модель в 2D
- **Optimize Layout** (`O`) - Оптимизировать расположение деталей
- **Generate AI Model** (`Ctrl+G`) - Сгенерировать 3D модель с помощью ИИ

### Настройки (`Ctrl+K` → введите "settings")
- **Change Language** - Сменить язык интерфейса
- **Toggle Theme** (`Ctrl+T`) - Переключить светлую/темную тему
- **Keyboard Shortcuts** (`Ctrl+Shift+K`) - Показать список горячих клавиш

### Помощь (`Ctrl+K` → введите "help")
- **Open Documentation** (`F1`) - Открыть документацию
- **About Pepakura Next** - Информация о приложении

## Расширение системы

### Добавление новой команды

1. Откройте файл `src/commands/commands.registry.ts`
2. Добавьте новую команду в массив `baseCommands`:

```typescript
{
  id: 'your.command.id',
  title: 'Command Title',
  description: 'Command description',
  icon: '🎯',
  category: 'tools', // или 'file', 'edit', 'view', 'export', 'settings', 'help'
  hotkey: 'Ctrl+Alt+X', // опционально
  action: () => {
    // Реализация команды
    console.log('Command executed')
    // Вызов существующей функции
  },
  keywords: ['ключевое', 'слово', 'search']
}
```

3. Команда автоматически появится в палитре

### Регистрация команды динамически

```typescript
import { registerCommand } from '@/commands/commands.registry'

registerCommand({
  id: 'dynamic.command',
  title: 'Dynamic Command',
  description: 'Added at runtime',
  category: 'tools',
  action: () => {
    // Действие
  }
})
```

### Интеграция с существующими компонентами

Для связи команд с реальными функциями:

```typescript
// В компоненте
import { registerCommand } from '@/commands/commands.registry'

onMounted(() => {
  registerCommand({
    id: 'component.specific',
    title: 'Component Action',
    description: 'Action specific to this component',
    category: 'tools',
    action: () => {
      // Вызов метода компонента
      componentMethod.value()
    }
  })
})

onUnmounted(() => {
  unregisterCommand('component.specific')
})
```

## Техническая архитектура

### Компоненты

1. **CommandPalette.vue** - Визуальный компонент палитры
2. **commands.registry.ts** - Реестр команд и логика поиска
3. **useCommandPalette.ts** - Композиция для управления состоянием
4. **hotkeys.service.ts** - Сервис для обработки горячих клавиш

### Поток данных

```
Пользователь → Горячая клавиша → useCommandPalette → CommandPalette
                     ↓
               hotkeys.service
                     ↓
           commands.registry.search()
                     ↓
           Отображение результатов
                     ↓
        Выполнение выбранной команды
```

## Отладка

### Консольные команды

```javascript
// Проверить зарегистрированные команды
console.log(commandRegistry.getAllCommands())

// Поиск команд
console.log(searchCommands('export'))

// Выполнить команду
executeCommand('file.new')
```

### Логирование

Все действия палитры логируются в консоль:
- Открытие/закрытие палитры
- Выполнение команд
- Ошибки поиска
