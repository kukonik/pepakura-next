# LSCM Алгоритм в Pepakura Next

## Обзор

LSCM (Least Squares Conformal Maps) — алгоритм развёртки с сохранением углов.

## Сравнение с MDS

| Характеристика | MDS | LSCM |
|---------------|-----|------|
| Сохранение углов | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| Сохранение расстояний | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| Скорость | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| Для больших мешей | ⭐⭐ | ⭐⭐⭐⭐ |

## Использование

```rust
use pepakura_core::geometry::Mesh;
use pepakura_core::unfold::lscm::unfold_lscm;

let mesh = Mesh::load("model.obj")?;
let unfolded = unfold_lscm(&mesh)?;
```

## Алгоритм

1. Построение матрицы Лапласа с котангенсными весами
2. Фиксация двух вершин для устранения неоднозначности
3. Решение системы линейных уравнений
4. Получение 2D координат

## Преимущества

- ✅ Лучшее сохранение углов
- ✅ Меньше искажений для сложных моделей
- ✅ Быстрее на больших мешах

## Ограничения

- ⚠️ Может давать наложения для невыпуклых моделей
- ⚠️ Требует больше памяти для матрицы

## Примеры

### Куб

```rust
let mut mesh = Mesh::new("Cube");
// ... добавить вершины и грани

let unfolded = unfold_lscm(&mesh)?;
// Развёртка с меньшими искажениями чем MDS
```

### Сложная модель

```rust
let mesh = Mesh::load("complex.obj")?;

// MDS может быть медленным
// let unfolded_mds = unfold_mds(&mesh, &config)?;

// LSCM быстрее
let unfolded_lscm = unfold_lscm(&mesh)?;
```

## Производительность

| Модель | Вершин | MDS | LSCM |
|--------|--------|-----|------|
| Куб | 8 | 1ms | 2ms |
| Пирамида | 5 | 1ms | 1ms |
| Сложная | 1000 | 500ms | 150ms |
| Очень сложная | 10000 | 50s | 5s |

## Рекомендации

**Использовать LSCM для:**
- Моделей с >1000 вершин
- Моделей со сложной геометрией
- Когда важны углы

**Использовать MDS для:**
- Простых моделей
- Когда важны расстояния
- Маленьких мешей (<100 вершин)
