# Топ-интеграции для Pepakura Next

Анализ экосистем GitHub и Hugging Face выявил следующие лучшие ресурсы для интеграции в проект Pepakura Next (3D → развёртка).

## Таблица рекомендаций

| Название | Источник | Применение в проекте | Сложность интеграции |
|----------|----------|----------------------|----------------------|
| TripoSR | [Hugging Face](https://huggingface.co/stabilityai/TripoSR) / [GitHub](https://github.com/VAST-AI-Research/TripoSR) | Генерация 3D-меша из одного изображения. Позволяет пользователям создавать 3D-модели для развёртки из фотографий. | Средняя. Требует интеграции Python-модели или использования ONNX runtime. В проекте уже есть заготовки (triposr.json). |
| Hunyuan3D-2 | [GitHub](https://github.com/Tencent-Hunyuan/Hunyuan3D-2) | Генерация высококачественных 3D-ассетов по текстовому описанию. Расширяет возможности создания моделей без исходных 3D-файлов. | Высокая. Большая модель требует значительных GPU ресурсов и сложной инфраструктуры инференса. |
| xatlas | [GitHub](https://github.com/jpcy/xatlas) | Библиотека для автоматической UV-развёртки 3D-мешей. Критична для преобразования 3D-модели в 2D-развёртку с минимальными искажениями. | Низкая. Чистая C-библиотека с простым API, легко интегрируется через FFI. |
| libnest2d | [GitHub](https://github.com/tamasmeszaros/libnest2d) | Библиотека для упаковки (nesting) 2D-полигонов на листе. Улучшает алгоритм размещения деталей развёртки, уменьшая waste материала. | Средняя. C++ библиотека, требуется создание биндингов или вызов через CLI. |

## Детали по каждой интеграции

### 1. TripoSR
- **Почему это лучшее решение**: State-of-the-art модель для Image-to-3D, быстрая (до 5 секунд), генерирует детализированные меши с текстурами.
- **Как интегрировать**: Использовать Hugging Face Transformers или ONNX-версию модели. Добавить в `crates/ai_bridge` вызов Python-скрипта или Rust-биндинги к ONNX.

### 2. Hunyuan3D-2
- **Почему это лучшее решение**: Наиболее продвинутая модель Text-to-3D с поддержкой генерации текстур и высоким разрешением. Поддерживает как текст, так и изображение на вход.
- **Как интегрировать**: Развернуть отдельный микросервис на Python с GPU, предоставить REST API. Взаимодействие через Tauri-команды.

### 3. xatlas
- **Почему это лучшее решение**: Простая, быстрая и надёжная библиотека UV-развёртки, используется во многих игровых движках. Поддерживает островные атласы.
- **Как интегрировать**: Скомпилировать как статическую библиотеку, добавить в `core` Rust-биндинги через `bindgen`. Вызывать из кода развёртки.

### 4. libnest2d
- **Почему это лучшее решение**: Мощная библиотека для nesting произвольных полигонов с поддержкой вращения и различных эвристик. Используется в PrusaSlicer.
- **Как интегрировать**: Использовать C++ биндинги или портировать алгоритмы на Rust. Можно запускать как внешний процесс.

## Следующие шаги

2. Добавить поддержку TripoSR через существующий AI-мост.
3. Оценить производительность Hunyuan3D-2 на целевом железе.
4. Заменить текущий алгоритм nesting на libnest2d для повышения эффективности упаковки.
