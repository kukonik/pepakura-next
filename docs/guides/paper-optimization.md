# Оптимизация моделей для бумаги

## Обзор

Функция оптимизации моделей для бумаги в Pepakura Next позволяет минимизировать отходы бумаги при печати 3D моделей и улучшить удобство сборки. Эта функция автоматически анализирует 3D модель и применяет различные оптимизации для более эффективного использования бумаги.

## Как использовать

1. Откройте проект с 3D моделью
2. Перейдите на вкладку "Бумажная развёртка"
3. Нажмите кнопку "Оптимизировать для бумаги"
4. Настройте параметры оптимизации в модальном окне
5. Нажмите "Оптимизировать модель"
6. Просмотрите результаты оптимизации

## Параметры оптимизации

### Параметры бумаги

- **Ширина листа (мм)**: Ширина листа бумаги в миллиметрах
- **Высота листа (мм)**: Высота листа бумаги в миллиметрах
- **Минимальный зазор (мм)**: Минимальное расстояние между элементами на листе

### Параметры вкладышей

- **Минимальная ширина вкладыша (мм)**: Минимальная ширина вкладышей для склеивания
- **Максимальный угол для автовкладышей (градусы)**: Максимальный угол между гранями для автоматического создания вкладышей

### Поля для печати

- **Добавить поля для печати**: Включить или отключить добавление полей для печати
- **Размер полей (мм)**: Размер полей для печати в миллиметрах

## Результаты оптимизации

После выполнения оптимизации вы получите следующую информацию:

- **Количество листов бумаги**: Сколько листов бумаги потребуется для печати модели
- **Использование бумаги**: Процент использования бумаги
- **Площадь модели (м²)**: Общая площадь модели
- **Рекомендации по сборке**: Полезные советы по сборке оптимизированной модели

## Алгоритмы оптимизации

### Анализ модели

Алгоритм начинает с анализа 3D модели для определения оптимальной стратегии разворачивания. Он учитывает количество граней, сложность модели и другие факторы.

### Разворачивание с оптимизациями

Модель разворачивается с учетом оптимизаций, направленных на минимизацию отходов бумаги. Это включает в себя оптимальное расположение элементов на листе.

### Добавление вкладышей

Автоматически добавляются вкладыши для склеивания граней. Размер и положение вкладышей определяются на основе угла между гранями и других параметров.

### Укладка элементов

Элементы укладываются на лист с минимальными отходами. Алгоритм старается максимально эффективно использовать пространство листа.

### Генерация рекомендаций

На основе анализа модели генерируются рекомендации по сборке, которые помогут пользователю правильно собрать модель.

## Примеры использования

### Простая модель

Для простой модели с небольшим количеством граней оптимизация может значительно сократить количество листов бумаги, необходимых для печати.

### Сложная модель

Для сложной модели с большим количеством граней оптимизация поможет упорядочить элементы на листах и сгенерировать полезные рекомендации по сборке.

## API

### Tauri команды

- `optimize_model_for_paper(model, params)`: Оптимизирует 3D модель для печати на бумаге
- `get_default_paper_optimize_params()`: Возвращает параметры оптимизации по умолчанию

### Параметры

```typescript
interface PaperOptimizeParams {
  sheetWidth: number
  sheetHeight: number
  minGap: number
  minTabWidth: number
  maxAutoTabAngle: number
  addPrintMargins: boolean
  marginSize: number
}
```

### Результаты

```typescript
interface PaperOptimizeResult {

}
