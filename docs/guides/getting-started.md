# Быстрый старт

## Требования

- Node.js 18+ и pnpm
- Rust 1.70+ и Cargo
- Python 3.11+ (опционально, для AI-бэкенда)

## Установка

```powershell
# Клонировать репозиторий
git clone https://github.com/your-repo/pepakura-next.git
cd pepakura-next

# Установить зависимости
pnpm install

# Сборка Rust-ядра
cargo build
Запуск
Веб-режим (разработка интерфейса)
cd packages/ui-desktop
pnpm dev
Откройте http://localhost:3004/
Десктопный режим (полная функциональность)
cd packages/ui-desktop
pnpm tauri dev
Базовое использование
Загрузка модели: Нажмите 📂 или перетащите файл .obj/.fbx/.gltf
Просмотр: Вращайте камеру (ЛКМ), масштабируйте (колёсико)
Разворачивание: Нажмите ✂️ для автоматического разворачивания
Экспорт: Сохраните развёртку в PDF
Структура проекта
См. Архитектура для подробного описания.
Дальнейшие шаги
Решение проблем — если что-то не работает
Соглашения по коду — если хотите внести вклад
Инструменты разработки — полезные скрипты
