# Руководство пользователя по работе с материалами в Pepakura Next

## Введение

Это руководство поможет вам эффективно использовать систему материалов в Pepakura Next. Система материалов позволяет создавать реалистичные визуальные эффекты для ваших 3D моделей с помощью PBR (Physically Based Rendering) материалов, текстур и пользовательских шейдеров.

## Основные понятия

### Что такое материал?

Материал определяет визуальные свойства поверхности 3D объекта. Он определяет, как свет взаимодействует с поверхностью объекта, что влияет на его внешний вид.

### Что такое PBR?

PBR (Physically Based Rendering) - это подход к рендерингу, который имитирует физическое поведение света в реальном мире. PBR материалы обеспечивают более реалистичный и предсказуемый внешний вид при различных условиях освещения.

### Основные параметры PBR материалов

1. **Albedo (основной цвет)** - базовый цвет поверхности
2. **Roughness (шероховатость)** - насколько гладкой или шероховатой является поверхность
3. **Metalness (металличность)** - насколько материал похож на металл
4. **Normal Map (нормальная карта)** - добавляет детали поверхности без увеличения количества полигонов
5. **AO Map (карта окружающего освещения)** - имитирует затенение в складках и углах
6. **Emissive (самосвечение)** - определяет, излучает ли поверхность свет

## Работа с материалами

### Создание нового материала

1. Откройте панель материалов в редакторе
2. Нажмите кнопку "Создать материал"
3. Выберите тип материала:
   - Базовый материал
   - PBR материал
   - Пользовательский материал
4. Настройте параметры материала

### Использование библиотеки материалов

Pepakura Next включает библиотеку предопределенных материалов:

1. Откройте панель материалов
2. Перейдите на вкладку "Библиотека"
3. Выберите категорию материалов (металлы, пластик, дерево и т.д.)
4. Выберите нужный материал из списка
5. Примените материал к выбранному объекту

### Настройка параметров PBR материала

1. Выберите объект в сцене
2. Откройте панель свойств материала
3. Настройте следующие параметры:
   - **Albedo**: Основной цвет материала
   - **Roughness**: Шероховатость поверхности (0 - гладкая, 1 - шероховатая)
   - **Metalness**: Металличность (0 - неметалл, 1 - металл)
   - **Normal Scale**: Интенсивность нормальной карты
   - **Emissive**: Цвет самосвечения

### Работа с текстурами

#### Загрузка текстур

1. В панели свойств материала нажмите кнопку "Загрузить текстуру"
2. Выберите тип текстуры:
   - Albedo Map
   - Normal Map
   - Roughness Map
   - Metalness Map
   - AO Map
   - Emissive Map
3. Выберите файл изображения
4. Настройте параметры текстуры (повторение, смещение, поворот)

#### Редактирование текстур

1. Выберите текстуру в панели свойств
2. Используйте инструменты редактирования текстур:
   - Изменение яркости/контрастности
   - Коррекция цвета
   - Наложение фильтров
   - Комбинирование нескольких текстур

## Библиотека стандартных материалов

### Металлы

- **Сталь**: Серебристо-серый металл с низкой шероховатостью
- **Алюминий**: Светло-серый металл с высоким отражением
- **Медь**: Красновато-коричневый металл
- **Золото**: Желтый металл с высоким отражением
- **Серебро**: Белый металл с высоким отражением

### Пластик

- **Глянцевый**: Гладкий пластик с высоким отражением
- **Матовый**: Шероховатый пластик без отражения
- **Прозрачный**: Прозрачный пластик с преломлением

### Дерево

- **Дуб**: Текстура дуба с характерным рисунком волокон
- **Сосна**: Текстура сосны с длинными волокнами
- **Бамбук**: Текстура бамбука с характерными узлами

### Камень

- **Гранит**: Текстура гранита с крупными кристаллами
- **Мрамор**: Текстура мрамора с плавными вихрями
- **Известняк**: Текстура известняка с пористой структурой

### Ткань

- **Хлопок**: Текстура хлопка с мягкой структурой
- **Шелк**: Гладкая ткань с высоким отражением
- **Деним**: Текстура джинсовой ткани

## Создание пользовательских материалов

### Использование шейдерного редактора

1. Создайте новый пользовательский материал
2. Откройте шейдерный редактор
3. Добавьте необходимые узлы:
   - Входные параметры (цвет, векторы, скаляры)
   - Математические операции
   - Текстурные сэмплеры
   - Выходные параметры
4. Соедините узлы для создания желаемого эффекта
5. Сохраните шейдер

### Примеры пользовательских материалов

#### Светящийся материал

```glsl
// Вершинный шейдер
varying vec3 vPosition;

void main() {
    vPosition = position;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}

// Фрагментный шейдер
varying vec3 vPosition;
uniform vec3 emissiveColor;
uniform float time;

void main() {
    float pulse = sin(time * 2.0) * 0.5 + 0.5;
    gl_FragColor = vec4(emissiveColor * pulse, 1.0);
}
```

#### Материал с эффектом воды

```glsl
// Вершинный шейдер
varying vec3 vNormal;
varying vec3 vPosition;

void main() {
    vNormal = normal;
    vPosition = position;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}

// Фрагментный шейдер
varying vec3 vNormal;
varying vec3 vPosition;
uniform float time;

void main() {
    // Создание эффекта волн
    float wave = sin(vPosition.x * 10.0 + time) * 0.05 +
                 sin(vPosition.z * 15.0 + time * 1.3) * 0.05;
    
    vec3 normal = normalize(vNormal + vec3(0.0, wave, 0.0));
    
    // Цвет воды
    vec3 waterColor = vec3(0.1, 0.3, 0.8);
    
    // Отражение
    vec3 lightDir = normalize(vec3(1.0, 1.0, 1.0));
    float reflection = max(0.0, dot(normal, lightDir));
    
    gl_FragColor = vec4(waterColor * (0.5 + reflection * 0.5), 0.8);
}
```

## Оптимизация материалов

### Рекомендации по производительности

1. Используйте сжатые форматы текстур (ASTC, ETC2, PVRTC)
2. Ограничьте размер текстур разумными значениями (обычно не более 2048x2048)
3. Используйте мипмаппинг для текстур
4. Объединяйте несколько текстур в одну атласную текстуру
5. Используйте LOD (уровни детализации) для материалов

### Управление качеством

Pepakura Next предоставляет настройки качества материалов:

1. **Низкое качество**: Используются базовые материалы без текстур
2. **Среднее качество**: Используются текстуры с пониженным разрешением
3. **Высокое качество**: Используются полные PBR материалы с высоким разрешением текстур

## Советы и рекомендации

### Создание реалистичных материалов

1. Изучайте реальные материалы в реальном мире
2. Используйте референсные изображения
3. Обращайте внимание на детали (царапины, пыль, влагу)
4. Используйте карты нормалей для добавления деталей
5. Экспериментируйте с параметрами шероховатости и металличности

### Работа с освещением

1. Используйте различные типы источников света (точечные, направленные, окружающие)
2. Настройте HDR окружение для более реалистичного отражения
3. Используйте карты освещения для имитации сложного освещения
4. Обращайте внимание на затенение в складках (AO карты)

## Устранение неполадок

### Распространенные проблемы

#### Материал выглядит плоским

**Причины:**
- Отсутствуют нормальные карты
- Неправильно настроено освещение
- Низкая шероховатость

**Решения:**
- Добавьте нормальную карту
- Настройте освещение
- Увеличьте значение шероховатости

#### Материал слишком темный

**Причины:**
- Низкая яркость albedo текстуры
- Недостаточное освещение
- Высокая шероховатость

**Решения:**
- Увеличьте яркость albedo текстуры
- Добавьте больше источников света
- Уменьшите значение шероховатости

#### Материал не реагирует на освещение

**Причины:**
- Используется базовый материал вместо PBR
- Неправильно настроен шейдер

**Решения:**
- Переключитесь на PBR материал
- Проверьте настройки шейдера

## Заключение

Система материалов Pepakura Next предоставляет мощные инструменты для создания реалистичных визуальных эффектов. Следуя рекомендациям из этого руководства, вы сможете создавать впечатляющие материалы для ваших 3D моделей.

Для получения дополнительной информации ознакомьтесь с технической документацией по архитектуре системы материалов.
