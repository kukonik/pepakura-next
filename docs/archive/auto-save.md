# Система автосохранения

## Обзор

Система автосохранения в Pepakura Next автоматически сохраняет прогресс пользователя на каждом этапе работы с проектом. Это обеспечивает защиту от потери данных при неожиданном закрытии приложения, сбоях системы или других проблемах.

## Как работает

Система автосохранения работает в фоновом режиме и сохраняет состояние проекта при следующих событиях:

1. **По времени**: Каждые 30 секунд, если в проекте были изменения
2. **По действиям**: При выполнении значимых действий (генерация модели, изменение параметров и т.д.)
3. **При смене фокуса**: Когда окно приложения теряет фокус

## Что сохраняется

Система автосохранения отслеживает и сохраняет следующую информацию:

### Общая информация о проекте
- Название проекта
- Дата создания и последнего изменения
- Настройки проекта

### 3D модель
- Исходная 3D модель
- Параметры генерации (для AI-моделей)
- История изменений модели
- Превью модели

### Развёртка
- Параметры разворачивания
- Развёрнутые элементы
- Швы и вкладыши
- Параметры оптимизации бумаги

### Настройки пользователя
- Предпочтения интерфейса
- Настройки AI
- Настройки экспорта

## Версионность

Система автосохранения поддерживает версионность, позволяя пользователю:

- Просматривать историю изменений проекта
- Восстанавливать предыдущие версии проекта
- Сравнивать изменения между версиями

По умолчанию сохраняется до 50 версий проекта. Пользователь может настроить количество сохраняемых версий или отключить ограничение.

## Восстановление сессий

При запуске приложения система автоматически проверяет наличие несохраненных сессий и предлагает восстановить их. Это особенно полезно после неожиданного закрытия приложения.

### Как восстановить сессию

1. При запуске приложения появится уведомление о наличии несохраненной сессии
2. Нажмите "Восстановить сессию" для восстановления
3. Приложение загрузит последнее сохраненное состояние проекта

## Облачная синхронизация

Система автосохранения поддерживает синхронизацию с облачными сервисами:

- **Google Drive**: Синхронизация через аккаунт Google
- **Dropbox**: Синхронизация через аккаунт Dropbox
- **Локальное хранилище**: Синхронизация с локальной папкой

### Настройка синхронизации

1. Откройте настройки проекта
2. Перейдите на вкладку "Синхронизация"
3. Выберите провайдера облачного хранилища
4. Авторизуйтесь в выбранном сервисе
5. Выберите папку для синхронизации

## Разрешение конфликтов

При синхронизации система может обнаружить конфликты версий. В этом случае:

1. Система уведомит пользователя о конфликте
2. Будет предложено выбрать версию для сохранения
3. Пользователь может сравнить версии перед выбором

## API

### Основные функции

```typescript
interface AutoSaveSystem {
  // Включить/выключить автосохранение
  setEnabled(enabled: boolean): void
  
  // Установить интервал автосохранения (в миллисекундах)
  setInterval(interval: number): void
  
  // Установить максимальное количество версий
  setMaxVersions(maxVersions: number): void
  
  // Восстановить проект из последней сохраненной версии
  restoreLastSession(): Promise<Project | null>
  
  // Получить список сохраненных версий
  getSavedVersions(): Promise<VersionInfo[]>
  
  // Восстановить проект из конкретной версии
  restoreVersion(versionId: string): Promise<Project>
  
  // Сравнить две версии проекта
  compareVersions(versionId1: string, versionId2: string): Promise<ComparisonResult>
}
```

### Структуры данных

```typescript
interface Project {
  id: string
  name: string
  createdAt: Date
  lastModified: Date
  settings: ProjectSettings
  model: ModelData
  unfold: UnfoldData
  // ... другие поля
}

interface VersionInfo {
  id: string
  timestamp: Date
  size: number
  description: string
}

interface ComparisonResult {
  added: Change[]
  modified: Change[]
  removed: Change[]
}

interface Change {
  path: string
  oldValue: any
  newValue: any
}
```

## Настройки автосохранения

Пользователь может настроить поведение системы автосохранения:

- **Интервал сохранения**: От 10 секунд до 5 минут
- **Триггеры сохранения**: Время, действия, смена фокуса
- **Количество версий**: От 10 до 100 версий
- **Синхронизация**: Включение/выключение облачной синхронизации

## Примеры использования

### Защита от потери данных

1. Пользователь работает над сложной моделью
2. Неожиданно отключается электричество
3. При следующем запуске приложения система предлагает восстановить сессию
4. Пользователь восстанавливает проект и продолжает работу

### Сравнение версий

1. Пользователь экспериментирует с параметрами разворачивания
2. После нескольких изменений решает, что исходная версия была лучше
3. Использует функцию сравнения версий для возврата к предыдущему состоянию
