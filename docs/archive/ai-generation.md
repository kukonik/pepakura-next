# Генерация 3D моделей с помощью AI

## Обзор

Pepakura Next включает в себя мощные функции генерации 3D моделей с помощью искусственного интеллекта. Эти функции позволяют создавать 3D модели из текстовых описаний или 2D изображений, что делает процесс создания бумажных моделей более доступным и удобным.

## Text-to-3D

Функция Text-to-3D позволяет создавать 3D модели на основе текстового описания. Она использует современные языковые модели для интерпретации описания и генерации соответствующей 3D модели.

### Как использовать

1. Откройте проект или создайте новый
2. Перейдите на вкладку "Текст в 3D"
3. Введите описание желаемой 3D модели
4. Нажмите "Сгенерировать модель"
5. Дождитесь завершения генерации
6. Просмотрите и при необходимости отредактируйте сгенерированную модель

### Примеры описаний

- "Простая лиса для детской поделки"
- "Здание средней школы с двумя этажами"
- "Космический корабль в стиле звёздных войн"
- "Дракон с открытым ртом и расправленными крыльями"

### Параметры генерации

- **Качество модели**: Определяет уровень детализации модели (низкое, среднее, высокое)
- **Стиль**: Выбор стиля модели (реалистичный, мультяшный, пиксель-арт и т.д.)
- **Цвет**: Основной цвет модели
- **Материал**: Тип материала (пластик, металл, дерево и т.д.)

## Image-to-3D

Функция Image-to-3D позволяет создавать 3D модели на основе 2D изображений. Она использует современные модели компьютерного зрения для анализа изображения и генерации соответствующей 3D модели.

### Как использовать

1. Откройте проект или создайте новый
2. Перейдите на вкладку "Изображение в 3D"
3. Загрузите изображение (JPG, PNG)
4. Нажмите "Сгенерировать модель"
5. Дождитесь завершения генерации
6. Просмотрите и при необходимости отредактируйте сгенерированную модель

### Рекомендации по изображениям

- Используйте изображения с четкими контурами
- Избегайте изображений с множеством объектов
- Используйте изображения с хорошим контрастом
- Предпочтение отдается изображениям с одного ракурса

## Интеграция с автосохранением

Все процессы генерации моделей интегрированы с системой автосохранения, что обеспечивает сохранение прогресса на каждом этапе. Это позволяет не терять данные при неожиданном закрытии приложения или других проблемах.

## API

### REST API

#### Text-to-3D

- **POST /api/text-to-3d/generate**
  - Генерирует 3D модель на основе текстового описания
  - Тело запроса: `{ "prompt": "string", "options": {} }`
  - Ответ: `{ "modelId": "string", "status": "string" }`

- **GET /api/text-to-3d/status/{modelId}**
  - Получает статус генерации модели
  - Ответ: `{ "status": "string", "progress": "number" }`

- **GET /api/text-to-3d/result/{modelId}**
  - Получает результат генерации модели
  - Ответ: `{ "model": {}, "previews": [] }`

#### Image-to-3D

- **POST /api/image-to-3d/generate**
  - Генерирует 3D модель на основе изображения
  - Тело запроса: `{ "image": "base64", "options": {} }`
  - Ответ: `{ "modelId": "string", "status": "string" }`

- **GET /api/image-to-3d/status/{modelId}**
  - Получает статус генерации модели
  - Ответ: `{ "status": "string", "progress": "number" }`

- **GET /api/image-to-3d/result/{modelId}**
  - Получает результат генерации модели
  - Ответ: `{ "model": {}, "previews": [] }`

### Клиентская библиотека

#### TextTo3DClient

```typescript
class TextTo3DClient {
  // Генерирует 3D модель на основе текстового описания
  async generateModel(prompt: string, options?: GenerationOptions): Promise<GenerationResult>
  
  // Получает статус генерации
  async getGenerationStatus(modelId: string): Promise<GenerationStatus>
  
  // Получает результат генерации
  async getGenerationResult(modelId: string): Promise<GenerationResult>
}
```

#### ImageTo3DClient

```typescript
class ImageTo3DClient {
  // Генерирует 3D модель на основе изображения

  // Получает результат генерации
  async getGenerationResult(modelId: string): Promise<GenerationResult>
}
```

## Примеры использования

### Создание модели животного

1. Откройте вкладку "Текст в 3D"
2. Введите: "Милый кот с большими глазами и пушистой шерстью"
3. Нажмите "Сгенерировать модель"
4. После генерации перейдите к разворачиванию

3. Нажмите "Сгенерировать модель"

## Оптимизация для слабых ПК

Все AI-функции оптимизированы для работы на слабых компьютерах:

- Используются квантованные модели для локальной работы
- Реализована фоновая обработка
- Динамическое снижение качества при необходимости
- Кэширование результатов для повторного использования
