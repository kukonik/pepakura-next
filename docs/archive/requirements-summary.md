# Сводка требований к проекту Pepakura Next

На основе анализа документации проекта.

## Функциональные требования

### 1. Генерация 3D моделей с помощью AI
- **Text-to-3D**: Создание 3D моделей из текстовых описаний.
  - Параметры: качество (низкое, среднее, высокое), стиль, цвет, материал.
  - API: REST endpoints для генерации, статуса, результата.
  - Клиентская библиотека: `TextTo3DClient`.
- **Image-to-3D**: Создание 3D моделей из 2D изображений.
  - Поддерживаемые форматы: JPG, PNG.
  - Рекомендации по изображениям.
  - API аналогично Text-to-3D.
- **Интеграция с автосохранением**: Сохранение прогресса на каждом этапе.

### 2. Оптимизация моделей для бумаги
- Минимизация отходов бумаги при печати.
- Автоматический анализ 3D модели и применение оптимизаций.
- Параметры: размеры листа, минимальный зазор, вкладыши, поля.
- Результаты: количество листов, процент использования бумаги, рекомендации по сборке.
- Алгоритмы: анализ модели, разворачивание с оптимизациями, добавление вкладышей, укладка элементов.
- API: Tauri команды `optimize_model_for_paper`, `get_default_paper_optimize_params`.

### 3. Система автосохранения
- Автоматическое сохранение прогресса по времени (каждые 30 сек), по действиям, при смене фокуса.
- Сохранение: общая информация о проекте, 3D модель, развёртка, настройки пользователя.
- Версионность: до 50 версий, восстановление предыдущих версий.
- Восстановление сессий после неожиданного закрытия.
- Облачная синхронизация: Google Drive, Dropbox, локальное хранилище.
- Разрешение конфликтов версий.
- API: `AutoSaveSystem` с методами управления.

### 4. Система материалов
- Поддержка типов материалов: PBR, стандартные, базовые.
- Обработка текстур: загрузка по URL или из ArrayBuffer.
- Поддерживаемые текстуры: baseColor, normal, roughness, metalness, emissive.
- Интеграция с загрузчиками моделей.
- Применение материалов к мешам.
- Оптимизация производительности: кэширование, управление памятью.
- Расширяемость: добавление новых типов материалов и свойств.

### 5. Система анимаций
- Создание, редактирование и воспроизведение скелетных анимаций.
- Компоненты: `AnimationSystem`, `AnimationClip`, `AnimationTransition`, `Skeleton`, `Pose`.
- Поддержка ключевых кадров, интерполяции, переходов между анимациями.
- Интеграция с Three.js.
- Редактор анимаций с таймлайном.
- Оптимизация производительности: кэширование клипов, ограничение частоты обновлений.

### 6. Универсальный загрузчик 3D моделей
- Поддержка форматов: GLTF/GLB, FBX, COLLADA (DAE), OBJ, STL, 3DS.
- Обработка материалов и текстур с поддержкой PBR.
- Базовые операции: масштабирование, поворот, перемещение.
- Архитектура: `UniversalModelLoader`, `FormatLoaders`, `MaterialProcessor`, `TransformationController`.
- Конвертация в унифицированный формат `PepaScene` и адаптер в Three.js.

### 7. Парсер формата PDO
- Чтение закрытого формата Pepakura Designer.
- Извлечение: 3D-геометрия, 2D-развёртки, линии сгиба, клапаны, номера частей.
- Конвертация в `PepaScene` с расширениями для PDO.
- Интеграция через Tauri API или WASM.

### 8. Формат TXT описания модели
- Структурированный формат для описания всего процесса: AI-генерация → 3D модель → бумажная развёртка.
- Секции: `[METADATA]`, `[GENERATION]`, `[MODEL_3D]`, `[UNFOLD]`, `[OPTIMIZATION]`.
- Использование для сериализации проекта, обмена, документирования.

### 9. UI/UX требования
- Десктопное приложение на Vue 3 + Tauri.
- Веб-версия на Vue 3 + Vite.
- 3D просмотрщик на Three.js.
- Панели: материалы, анимации, оптимизация бумаги, автосохранение.
- Адаптивный интерфейс с режимами для новичков и профессионалов.
- Локализация, темы оформления, доступность.

## Нефункциональные требования

### Производительность
- Время генерации модели < 30 секунд.
- Время развёртки < 10 секунд.
- Время запуска приложения < 3 секунд.
- Использование памяти < 500 MB при работе.
- Поддержка слабых ПК: динамическая оптимизация, фоновая обработка, кэширование.

### Безопасность
- Шифрование проектов (AES-256).
- Б передача данных (TLS 1.3).
- Аутентификация пользователей (OAuth2.0).
- Защита от вредоносного кода в плагинах.

### Надёжность
- Автосохранение для защиты от потери данных.
- Восстановление сессий после сбоев.
- Облачная синхронизация с разрешением конфликтов.
- Тестирование: покрытие кода > 90%, 100% успешных тестов.

### Совместимость
- Поддержка Windows, macOS, Linux.
- Поддержка браузеров: Chrome, Firefox, Safari (веб-версия).
- Поддержка форматов 3D моделей: GLTF, FBX, OBJ, STL, PDO и др.
- Поддержка форматов экспорта: PDF, SVG, DXF.

### Масштабируемость
- Архитектура монорепозитория с пакетами (ui-desktop, core, shared, backend-python).
- Возможность добавления плагинов.
- Облачная инфраструктура для будущего роста.

## Архитектурные решения

### Фронтенд
- Фреймворк: Vue 3 + TypeScript.
- Состояние: Pinia.
- Стили: TailwindCSS.
- Сборка: Vite.
- 3D рендеринг: Three.js.

### Бэкенд (десктоп)
- Основной язык: Rust.
- Фреймворк: Tauri.
- AI интеграция: Ollama, OpenAI API.

### Бэкенд (веб/облако)
- Python (FastAPI/Flask) для AI и экспорта.
- Возможность использования Rust (Axum) для облачных сервисов.

### Монорепозиторий
- Менеджер пакетов: pnpm.
- Структура workspace-based.

### Унифицированная архитектура форматов
- Все форматы конвертируются в промежуточный формат `PepaScene`.
- Адаптер в Three.js для рендеринга.
- Изолированные парсеры для каждого формата.

## Форматы файлов

### Входные форматы
- 3D модели: OBJ, FBX, GLTF/GLB, COLLADA (DAE), STL, 3DS, PDO.
- Изображения: JPG, PNG (для Image-to-3D).
- Текстовые описания (для Text-to-3D).

### Внутренние форматы
- `PepaScene` (унифицированный промежуточный формат).
- TXT описание модели (сериализация проекта).

### Выходные форматы
- Бумажные развёртки: PDF, SVG, DXF.
- 3D модели: GLB, OBJ (для экспорта).
- Инструкции по сборке: PDF, HTML.

## Интеграции

### AI
- Локальные модели через Ollama.
- Облачные API (OpenAI, другие провайдеры).
- Генерация швов с помощью AI.

### Облачные сервисы
- Google Drive, Dropbox для синхронизации.
- Облачные вычисления для тяжёлых операций.

### CAD/Blender
- Планируется интеграция с Blender (аддон).
- Импорт из CAD систем (AutoCAD, SolidWorks, Fusion 360, FreeCAD, OpenSCAD).

### Плагины
- Система плагинов для расширения функциональности.
- API для разработчиков, менеджер плагинов, sandbox для безопасности.
