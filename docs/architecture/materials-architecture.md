# Архитектура системы материалов в Pepakura Next

## Обзор

Система материалов в Pepakura Next предоставляет мощные возможности для работы с различными типами материалов, включая PBR (Physically Based Rendering) материалы, текстуры и пользовательские шейдеры. Система спроектирована для обеспечения гибкости, производительности и простоты использования.

## Основные компоненты

### 1. MaterialProcessor

`MaterialProcessor` - это основной класс для обработки материалов и текстур. Он отвечает за:

- Загрузку и обработку различных типов текстур
- Создание и настройку материалов Three.js
- Поддержку PBR материалов с различными параметрами
- Интеграцию с системой рендеринга

#### Основные методы:

```typescript
class MaterialProcessor {
  // Загрузка текстуры из файла
  public async loadTexture(path: string): Promise<THREE.Texture>
  
  // Создание базового материала
  public createBasicMaterial(options: BasicMaterialOptions): THREE.Material
  
  // Создание PBR материала
  public createPBRMaterial(options: PBRMaterialOptions): THREE.MeshStandardMaterial
  
  // Создание пользовательского материала
  public createCustomMaterial(shader: string, uniforms: any): THREE.ShaderMaterial
  
  // Применение текстуры к материалу
  public applyTextureToMaterial(material: THREE.Material, texture: THREE.Texture, mapType: string)
}
```

### 2. Типы материалов

#### Базовые материалы
- `BasicMaterial` - Простой материал без освещения
- `LambertMaterial` - Материал с диффузным освещением
- `PhongMaterial` - Материал с диффузным и зеркальным освещением

#### PBR материалы
- `StandardMaterial` - Стандартный PBR материал с параметрами:
  - `albedo` (основной цвет)
  - `roughness` (шероховатость)
  - `metalness` (металличность)
  - `normalMap` (нормальная карта)
  - `aoMap` (карта окружающего освещения)
  - `emissive` (самосвечение)

### 3. Система текстур

Система текстур поддерживает следующие типы:

- **Albedo/Diffuse** - Основная цветовая текстура
- **Normal Map** - Нормальная карта для детализации поверхности
- **Roughness Map** - Карта шероховатости
- **Metalness Map** - Карта металличности
- **AO Map** - Карта окружающего освещения
- **Emissive Map** - Карта самосвечения
- **Alpha Map** - Карта прозрачности

## Интеграция с рендерером

Система материалов тесно интегрирована с рендерером Three.js и предоставляет следующие возможности:

- Автоматическая настройка материалов при загрузке моделей
- Поддержка различных типов освещения
- Оптимизация рендеринга для повышения производительности
- Поддержка пользовательских шейдеров

## API использования

### Создание PBR материала

```typescript
const materialProcessor = new MaterialProcessor();

const pbrMaterial = materialProcessor.createPBRMaterial({
  albedo: new THREE.Color(0.8, 0.2, 0.1),
  roughness: 0.3,
  metalness: 0.8,
  // Загрузка текстур
  albedoMap: await materialProcessor.loadTexture('path/to/albedo.jpg'),
  normalMap: await materialProcessor.loadTexture('path/to/normal.jpg'),
  roughnessMap: await materialProcessor.loadTexture('path/to/roughness.jpg'),
  metalnessMap: await materialProcessor.loadTexture('path/to/metalness.jpg')
});
```

### Применение материала к мешу

```typescript
// Предположим, у нас есть меш и материал
const mesh = new THREE.Mesh(geometry, material);

// Применяем материал к мешу
mesh.material = pbrMaterial;
```

## Библиотека стандартных материалов

Система включает библиотеку предопределенных материалов:

- **Металлы**: Сталь, Алюминий, Медь, Золото, Серебро
- **Пластик**: Глянцевый, Матовый, Прозрачный
- **Дерево**: Дуб, Сосна, Бамбук
- **Камень**: Гранит, Мрамор, Известняк
- **Ткань**: Хлопок, Шелк, Деним

Каждый материал в библиотеке имеет предопределенные параметры PBR и набор текстур.

## Производительность

Система материалов оптимизирована для:

- Эффективной работы с текстурами (использование мипмаппинга, сжатия)
- Кэширования материалов и текстур
- Минимизации перерисовки при изменении материалов
- Поддержки LOD (уровней детализации) для текстур

## Расширяемость

Система спроектирована для легкого расширения:

- Добавление новых типов материалов
- Создание пользовательских шейдеров
- Интеграция с внешними библиотеками материалов
- Поддержка новых форматов текстур

## Заключение

Система материалов Pepakura Next предоставляет мощные и гибкие возможности для работы с визуальными эффектами в 3D моделях. Она сочетает в себе простоту использования с возможностью тонкой настройки, что делает её подходящей как для начинающих пользователей, так и для профессионалов.
