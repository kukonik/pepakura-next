# Архитектура парсера формата PDO

## Обзор

PDO — закрытый формат Pepakura Designer, содержащий:
- 3D-геометрию (вершины, полигоны)
- 2D-развёртки (layout на листах)
- Линии сгиба, клапаны, номера частей

## Файлы

### `crates/pepakura_core/src/pdo_parser.rs`
Парсер бинарного формата PDO:
- `PdoHeader` — заголовок файла
- `PdoVertex` — вершина 3D-модели
- `PdoFace` — треугольник
- `PdoModel` — полная 3D-информация

### `crates/pepakura_core/src/pdo_to_pepa.rs`
Конвертер в унифицированный формат:
- `PepaScene` — общая структура
- `PepaExtensions.pdo` — PDO-специфичные данные
- `PepaUnfoldedPart`, `PepaFoldLine`, `PepaGlueTab` — 2D-информация

### `packages/ui-desktop/src/utils/pepa-converters.ts`
TypeScript-заглушка:
- `convertPDOToPepaScene()` — интеграция с Rust/WASM
- Поддержка через Tauri-вызовы

## Интеграция

1. **Tauri API** — вызов `pepakura_core` из TypeScript
2. **WASM** — опционально, для браузерного режима
3. **PDO Extensions** — хранение 2D-данных в `PepaScene.extensions.pdo`
