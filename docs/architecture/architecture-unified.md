# Унифицированная архитектура форматов

## Обзор

Все 3D-форматы (OBJ, FBX, GLTF, DAE, STL, PLY, PDO) конвертируются в единый промежуточный формат `PepaScene`, который затем рендерится через адаптер в Three.js.

## Файлы

### `types/pepa-types.ts`
Унифицированные типы данных:
- `PepaTopology` - тип топологии (треугольник, квад, многоугольник)
- `PepaMaterial` - материал с поддержкой текстур
- `PepaMesh` - геометрия меша
- `PepaScene` - полная сцена
- Утилиты: `computeBoundingBox`, `triangulateQuadIndices`, `triangulateNgonIndices`

### `utils/pepa-scene-adapter.ts`
Адаптер для конвертации в Three.js:
- `createThreeMaterial()` - конвертация материала
- `createThreeGeometry()` - конвертация геометрии
- `createThreeMesh()` - создание меша
- `createThreeObjectFromPepa()` - основная функция конвертации
- `centerCameraOnObject()` - центрирование камеры

### `utils/parser-example.ts`
Примеры парсеров для будущих форматов:
- `parseCustomFormat()` - пример парсера бинарного формата
- `convertGLTFToPepaScene()` - заглушка для GLTF
- `convertOBJToPepaScene()` - заглушка для OBJ
- `convertFBXToPepaScene()` - заглушка для FBX

## Преимущества

1. **Единая точка входа** - все форматы обрабатываются одинаково
2. **Изолированные парсеры** - каждый формат имеет свой парсер, не влияющий на другие
3. **Типобезопасность** - полная проверка типов на этапе компиляции
4. **Расширяемость** - легко добавить новый формат (например, PDO)
5. **Тестирование** - парсеры можно тестировать независимо от рендерера
