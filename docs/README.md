# Документация Pepakura Next

## Обзор

Pepakura Next - это современный инструмент для создания бумажных моделей 3D объектов с использованием искусственного интеллекта. Проект сочетает в себе мощные алгоритмы разворачивания 3D моделей, AI-генерацию и оптимизацию для печати на бумаге.

## Основные функции

### Генерация 3D моделей с помощью AI
- [Text-to-3D](ai-generation.md): Создание 3D моделей из текстовых описаний
- [Image-to-3D](ai-generation.md): Создание 3D моделей из 2D изображений

### Оптимизация для бумаги
- [Оптимизация моделей для бумаги](paper-optimization.md): Минимизация отходов бумаги и улучшение удобства сборки

### Система автосохранения
- [Система автосохранения](auto-save.md): Автоматическое сохранение прогресса на каждом этапе

### Материалы и анимации
- [Система материалов](materials.md): Обработка и применение материалов к 3D моделям
- [Система анимаций](animations.md): Создание, редактирование и воспроизведение скелетных анимаций

### Описание моделей
- [Формат TXT описания модели](model-description-format.md): Структурированный формат описания для процесса AI-генерация > 2D/3D модель > 2D бумажная развёртка

## Архитектура проекта

### Фронтенд
- **Фреймворк**: Vue 3 + TypeScript
- **Состояние**: Pinia
- **Стили**: TailwindCSS
- **Сборка**: Vite

### Бэкенд
- **Основной язык**: Rust
- **Фреймворк**: Tauri
- **AI интеграция**: Ollama, OpenAI API

### Монорепозиторий
- **Менеджер пакетов**: pnpm
- **Структура**: Workspace-based архитектура

## Установка и запуск

### Требования
- Node.js 16+
- Rust toolchain
- pnpm
- Ollama (для локальных AI моделей)

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd pepakura-next

# Установка зависимостей
pnpm install

# Установка Rust toolchain (если не установлен)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Установка Ollama (для локальных AI моделей)
# Следуйте инструкциям на https://ollama.ai/
```

### Запуск

```bash
# Запуск веб-версии
pnpm run dev:web

# Запуск десктоп-версии
pnpm run dev:desktop

# Сборка для продакшена
pnpm run build
```

## Разработка

### Структура проекта

```
pepakura-next/
├── packages/
│   ├── ui-desktop/     # Десктоп-приложение
│   ├── ui-web/         # Веб-приложение
│   ├── core/           # Ядро приложения (Rust)
│   └── shared/        # Общий код
├── docs/               # Документация
├── scripts/            # Скрипты сборки и развертывания
└── tests/             # Тесты
```

4. Обновите документацию
5. Создайте pull request

## Тестирование

### Запуск тестов

```bash
# Запуск всех тестов
pnpm test

# Запуск тестов для конкретного пакета
pnpm test --filter ui-desktop

# Запуск тестов с покрытием
pnpm test:coverage
```

### Типы тестов

- **Модульные тесты**: Тестирование отдельных функций и компонентов
- **Интеграционные тесты**: Тестирование взаимодействия между компонентами
- **E2E тесты**: Тестирование полного пользовательского сценария

## Деплой

### Веб-версия

```bash
# Сборка веб-версии
pnpm build:web

# Деплой на Vercel
vercel --prod
```

### Десктоп-версия

```bash
# Сборка десктоп-версии для всех платформ
pnpm build:desktop

# Сборка для конкретной платформы
pnpm build:desktop --platform windows
```
