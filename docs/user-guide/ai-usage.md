# 📚 Использование AI-функций в Pepakura Next

## Обзор

AI-функции Pepakura Next помогают автоматизировать и улучшить процесс создания бумажных моделей. С помощью искусственного интеллекта вы можете:

- **Анализировать 3D-модели** и получать рекомендации по развёртке
- **Генерировать инструкции** по сборке на естественном языке
- **Задавать вопросы** AI-помощнику по любым аспектам papercraft
- **Кэшировать ответы** для мгновенного доступа к часто задаваемым вопросам
- **Получать ответы потоково** с помощью AI стриминга

## Быстрый старт

### 1. Настройка AI
1. Установите **Ollama** (рекомендуется) или настройте **OpenAI**
2. В Pepakura Next откройте **Настройки → AI**
3. Выберите провайдера, укажите URL (для Ollama: `http://localhost:11434`)
4. Нажмите **"Проверить подключение"**

### 2. Первое использование
- **AI-рекомендации по развёртке**: Загрузите модель, нажмите "AI-рекомендации" на панели развёртки
- **AI-чат**: Откройте боковую панель "AI-помощник" и задайте вопрос
- **Генерация инструкций**: После развёртки нажмите "Сгенерировать инструкции с AI"

## Технические детали

### Архитектура AI-модуля
```
Frontend (Vue) → Tauri Commands → Rust Core (pepakura_core) → AI Provider (Ollama/OpenAI)
```

### Поддерживаемые провайдеры
| Провайдер | Локальный | Бесплатный | Модели | Рекомендация |
|-----------|-----------|------------|--------|--------------|
| Ollama | Да | Да | llama3.2, mistral, gemma | Для конфиденциальности |
| OpenAI | Нет | Нет | GPT-4, GPT-3.5 | Для мощности |

### Производительность
| Операция | Время (кэш) | Время (первый запрос) | Ускорение |
|----------|-------------|------------------------|-----------|
| AI-рекомендация | <1 мс | 2-5 сек | 5000x |
| Генерация инструкций | <1 мс | 3-7 сек | 7000x |
| AI-чат (стриминг) | <100 мс | 1-3 сек | 30x |

## Расширенные возможности

### AI кэширование
Включено по умолчанию. Сохраняет ответы на локальном диске в зашифрованном виде.

**Управление кэшем:**
- **Просмотр статистики**: Настройки → AI → "Статистика кэша"
- **Очистка кэша**: Настройки → AI → "Очистить кэш"
- **Отключение**: Настройки → AI → "Включить кэширование" (снять галочку)

### AI стриминг
Позволяет видеть ответ по мере генерации. Первые слова появляются через <100 мс.

**Настройки:**
- Включение/выключение: Настройки → AI → "Включить стриминг"
- Скорость стриминга регулируется автоматически

### Кастомные промпты
Вы можете создавать собственные шаблоны промптов для часто выполняемых задач.

**Формат файла:** `custom_prompts.json`
```json
{
  "prompts": [
    {
      "name": "Анализ сложности",
      "template": "Проанализируй сложность модели {model_name} для новичка"
    }
  ]
}
```

## Устранение неполадок

### Диагностика проблем
1. **Проверьте логи AI**: `Настройки → О программе → Открыть логи`
2. **Тест подключения**: `Настройки → AI → Проверить подключение`
3. **Обновите модель Ollama**: `ollama pull llama3.2`

### Частые ошибки и решения
| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Не удалось подключиться к Ollama" | Ollama не запущен | Запустите `ollama serve` |
| "Модель не найдена" | Модель не загружена | Выполните `ollama pull llama3.2` |
| "AI отвечает медленно" | Слабое железо | Используйте модель gemma:2b |
| "Пустой ответ" | Нечёткий промпт | Переформулируйте вопрос |

## Интеграция с рабочим процессом

### Типичный workflow с AI
1. **Импорт модели** → OBJ/STL/PDO
2. **AI-анализ** → Получение рекомендаций по алгоритму развёртки
3. **Развёртка** → С применением AI-советов
4. **Генерация инструкций** → AI создаёт пошаговое руководство
5. **Экспорт** → PDF/SVG с AI-оптимизацией

### Советы по эффективному использованию
1. **Используйте конкретные промпты** — чем точнее вопрос, тем лучше ответ
2. **Сохраняйте историю диалогов** — для продолжения контекста
3. **Включите кэширование** — для повторяющихся задач
4. **Экспериментируйте с моделями** — разные модели дают разные результаты
