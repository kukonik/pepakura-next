## Начало работы

### Системные требования

- **ОС**: Windows 10/11, macOS 11+, или Ubuntu 20.04+
- **ОЗУ**: 4 GB (минимум), 8 GB (рекомендуется)
- **Место**: 500 MB свободного места

### Установка

1. Скачайте инсталлятор с [GitHub Releases](https://github.com/pepakura-next/pepakura-next/releases)
2. Запустите установщик
3. Следуйте инструкциям мастера установки

### Первый запуск

При первом запуске вы увидите главный экран:

![Dashboard](images/dashboard.png)

1. Нажмите **"Новый проект"**
2. Введите имя проекта
3. Нажмите **"Создать"**

## Импорт моделей

### Поддерживаемые форматы

- **PDO** — Pepakura Designer (родной формат)
- **OBJ** — Wavefront OBJ
- **STL** — Стереолитография
- **PLY** — Polygon File Format

### Импорт из файла

1. Откройте проект
2. Нажмите **"Импортировать модель"**
3. Выберите файл в одном из поддерживаемых форматов
4. Модель отобразится в 3D-вьювере

### Настройки импорта

#### Единицы измерения

Выберите единицы измерения исходной модели:
- **Миллиметры** (рекомендуется для печати)
- **Сантиметры**
- **Дюймы**

#### Масштабирование

Автоматически масштабируй модель под размер:
- **Оригинал** (без изменений)
- **Подогнать под A4**
- **Пользовательский масштаб**

### Решение проблем

#### Модель не импортируется

Проверьте:
- Файл не повреждён
- Формат поддерживается
- Файл < 100 MB

#### Ошибка "Некорректная геометрия"

Модель должна быть:
- Замкнутой (manifold)
- Без самопересечений
- С корректными нормалями

## Развёртка

### Алгоритм MDS

Приложение использует Multidimensional Scaling для проекции 3D → 2D.

### Параметры развёртки

#### Сохранение деталей

- **Включено**: минимизирует искажения текстур
- **Выключено**: быстрее, но больше искажений

#### Максимум итераций

Больше итераций = точнее результат, но медленнее.

Рекомендуется: **100-200**

#### Допуск сходимости

Меньшее значение = точнее, но может не сойтись.

Рекомендуется: **0.001**

### Просмотр развёртки

После развёртки вы увидите:

- 2D-развёртку в основном окне
- 3D-превью с подсвеченными гранями
- Панель инструментов для навигации

### Редактирование развёртки

#### Перемещение деталей

1. Выберите деталь кликом
2. Перетащите на новое место
3. Отпустите для фиксации

#### Поворот деталей

1. Выберите деталь
2. Используйте колесо мыши для поворота
3. Или введите точный угол в панели свойств

#### Масштабирование деталей

1. Выберите деталь
2. Используйте Ctrl + колесо мыши
3. Или введите масштаб в панели свойств

## Экспорт

### Форматы экспорта

#### SVG (рекомендуется)

Векторный формат для печати и редактирования.

**Преимущества:**
- Масштабируется без потерь
- Редактируется в Illustrator/Inkscape
- Поддерживает слои

#### PDF

Готов к печати сразу.

**Преимущества:**
- Кроссплатформенный
- Встроенные шрифты
- Поддержка CMYK

#### DXF

Для CAD-систем и лазерной резки.

### Настройки экспорта

#### Размер страницы

- **A4** (210 × 297 мм)
- **A3** (297 × 420 мм)
- **Custom** (пользовательский)

#### Масштаб

Укажите мм на единицу модели.

Например: `1.0` = 1 единица = 1 мм.

#### Линии

- **Линии реза**: сплошные, цвет красный
- **Линии сгиба**: пунктирные, цвет синий
- **Номера деталей**: текст, чёрный

### Печать

1. Экспортируйте в PDF
2. Откройте в Adobe Reader или браузере
3. Печать → "Actual Size" (без масштабирования)
4. Используйте плотную бумагу (120-200 g/m²)

## Решение проблем

### Частые проблемы

#### Приложение не запускается

**Windows:**
- Проверьте наличие .NET Framework 4.8+
- Запустите от имени администратора
- Отключите антивирус временно

**macOS:**
- Разрешите в System Preferences → Security
- Проверьте совместимость версии macOS

#### Развёртка сходится долго

**Причины:**
- Слишком сложная модель (>10k граней)
- Высокие параметры точности

**Решение:**
- Уменьшите max_iterations до 50
- Увеличьте tolerance до 0.01
- Упростите модель в 3D-редакторе

#### SVG не открывается в браузере

- Проверьте размер файла (< 10 MB)
- Попробуйте открыть в Inkscape
- Отключите "show_vertex_ids" при экспорте

#### AI не отвечает

- Проверьте, что Ollama запущен
- Проверьте URL подключения
- Попробуйте другую модель

### Логи приложения

Логи находятся:

- **Windows**: `%APPDATA%\com.pepakura.next\logs\`
- **macOS**: `~/Library/Logs/com.pepakura.next/`
- **Linux**: `~/.cache/com.pepakura.next/logs/`

### Связь с поддержкой

Если проблема не решена:

1. Откройте issue на [GitHub](https://github.com/pepakura-next/pepakura-next/issues)
2. Приложите логи
3. Укажите версию приложения
4. Опишите шаги для воспроизведения
