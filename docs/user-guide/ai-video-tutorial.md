# Видео-туториал: Использование AI-функций в Pepakura Next

## Сценарий видео (2-3 минуты)

### Вступление (0:00 - 0:20)
- Приветствие: "Здравствуйте! В этом видео мы покажем, как использовать AI-функции в Pepakura Next для улучшения вашего рабочего процесса создания бумажных моделей."
- Краткий обзор: "Вы узнаете, как настроить AI-помощника, получать рекомендации по развёртке, генерировать инструкции по сборке и использовать AI-чат для решения проблем."

### Часть 1: Настройка AI (0:20 - 0:50)
- "Сначала убедитесь, что у вас установлен Ollama для локальной работы AI. Если нет, скачайте его с сайта ollama.ai."
- Демонстрация: "Откройте настройки Pepakura Next, перейдите в раздел 'AI'."
- "Выберите провайдера: Ollama для локальной работы или OpenAI для облачной."
- "Укажите URL Ollama (по умолчанию http://localhost:11434) и выберите модель, например llama3.2."
- "Нажмите 'Проверить подключение'. Если всё настроено правильно, вы увидите статус 'Подключено'."

### Часть 2: Использование AI-помощника для развёртки (0:50 - 1:30)
- "Загрузите 3D-модель, например куб.obj."
- "Перейдите на вкладку 'Развёртка' и нажмите 'AI-рекомендации'."
- "AI проанализирует модель и предложит оптимальный алгоритм развёртки (MDS или LSCM), параметры и советы по улучшению."
- "Примените рекомендации и запустите развёртку. Вы увидите, как AI помогает ускорить процесс и улучшить качество."

### Часть 3: Генерация инструкций по сборке (1:30 - 2:00)
- "После развёртки перейдите на вкладку 'Экспорт'."
- "Нажмите 'Сгенерировать инструкции с AI'."
- "AI создаст пошаговые инструкции по сборке модели на русском языке, включая советы по склейке, нумерацию деталей и рекомендации по бумаге."
- "Вы можете экспортировать инструкции в PDF или сохранить как текстовый файл."

### Часть 4: AI-чат для решения проблем (2:00 - 2:30)
- "Откройте боковую панель 'AI-помощник'."
- "Задайте вопрос, например: 'Какую бумагу выбрать для модели корабля?' или 'Как исправить перекрывающиеся грани?'"
- "AI ответит в реальном времени с полезными советами. Вы также можете использовать историю диалога для уточнения."
- "Покажите, как использовать кнопку 'Копировать ответ' и 'Сохранить в историю'."

### Заключение (2:30 - 3:00)
- "Итак, AI-функции Pepakura Next позволяют: автоматически анализировать модели, генерировать инструкции и получать экспертные советы через чат."
- "Не забудьте включить кэширование AI в настройках для ускорения повторных запросов."
- "Если у вас есть вопросы, посетите нашу документацию или задайте вопрос в сообществе."
- "Спасибо за просмотр! Подписывайтесь на наш канал для новых туториалов."

## Требования к видео
- Разрешение: 1920x1080
- Длительность: 2-3 минуты
- Субтитры: рекомендуется добавить русские субтитры
- Фон: чистый, профессиональный
- Музыка: лёгкая фоновая без слов

## Структура монтажа
1. Интро с логотипом (5 сек)
2. Основные части (как выше)
3. Анимации переходов между шагами
4. Крупные планы на важных элементах UI
5. Outro с призывом к действию
