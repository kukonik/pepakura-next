# FAQ по AI-функциям Pepakura Next

## Общие вопросы

### 1. Что такое AI-помощник в Pepakura Next?
AI-помощник — это интегрированная система искусственного интеллекта, которая помогает:
- Анализировать 3D-модели и рекомендовать алгоритмы развёртки
- Генерировать пошаговые инструкции по сборке
- Отвечать на вопросы по papercraft через чат
- Оптимизировать параметры развёртки

### 2. Какие AI-провайдеры поддерживаются?
- **Ollama** (локальный, бесплатный) — рекомендуется для конфиденциальности и скорости
- **OpenAI** (облачный, платный) — для более мощных моделей (GPT-4, GPT-3.5)

### 3. Нужен ли интернет для работы AI?
- Для Ollama интернет не требуется после загрузки модели.
- Для OpenAI требуется стабильное интернет-соединение.

## Установка и настройка Ollama

### 4. Как установить Ollama?
- **Windows**: Скачайте установщик с [ollama.ai](https://ollama.ai) и запустите.
- **macOS**: `brew install ollama` или скачайте с сайта.
- **Linux**: `curl -fsSL https://ollama.ai/install.sh | sh`

### 5. Как проверить, что Ollama работает?
Откройте терминал и выполните:
```bash
ollama list
```
Если видите список моделей, Ollama работает.

### 6. Какие модели Ollama рекомендуются?
- `llama3.2` (баланс скорости и качества)
- `mistral` (хорошо для инструкций)
- `gemma` (лёгкая модель)

Загрузите модель:
```bash
ollama pull llama3.2
```

## Проблемы с подключением

### 7. Ошибка "Не удалось подключиться к Ollama"
**Причины:**
- Ollama не запущен
- Неправильный URL
- Брандмауэр блокирует порт 11434

**Решение:**
1. Запустите Ollama: `ollama serve`
2. Проверьте URL в настройках Pepakura Next: `http://localhost:11434`
3. Разрешите Ollama в брандмауэре
4. Перезапустите приложение

### 8. Ошибка "Модель не найдена"
**Решение:**
1. Убедитесь, что модель загружена: `ollama list`
2. Если модели нет, загрузите: `ollama pull llama3.2`
3. В настройках Pepakura Next укажите правильное имя модели

### 9. Как изменить URL Ollama, если он работает на другом порту?
В настройках Pepakura Next (Настройки → AI) укажите полный URL, например:
- `http://localhost:11435`
- `http://192.168.1.10:11434`

## Производительность

### 10. AI отвечает медленно (более 10 секунд)
**Причины:**
- Слабое железо (мало RAM/CPU)
- Большая модель (например, llama3.2 7B требует 8 GB RAM)
- Сеть (для OpenAI)

**Решение:**
1. Используйте более лёгкую модель: `gemma:2b`
2. Увеличьте объём оперативной памяти
3. Включите кэширование AI в настройках
4. Для OpenAI проверьте скорость интернета

### 11. Как ускорить AI-ответы?
- Включите **AI кэширование** (настройки → AI → Кэширование)
- Используйте **AI стриминг** для мгновенного получения первых токенов
- Закройте другие ресурсоёмкие приложения

### 12. Приложение зависает при использовании AI
**Решение:**
1. Уменьшите размер модели
2. Выделите больше памяти для Ollama: `OLLAMA_NUM_PARALLEL=2 ollama serve`
3. Обновите драйверы видеокарты (если используется GPU)

## Функциональность AI

### 13. Какие вопросы можно задавать AI-помощнику?
Примеры:
- "Какую бумагу выбрать для модели корабля?"
- "Как исправить перекрывающиеся грани?"
- "Как склеить мелкие детали?"
- "Как оптимизировать раскладку для экономии бумаги?"
- "Какой клей лучше использовать?"

### 14. AI даёт неправильные или неточные ответы
**Причины:**
- Модель недостаточно обучена
- Нечёткий промпт

**Решение:**
1. Переформулируйте вопрос более конкретно
2. Используйте более свежую модель (например, llama3.2 вместо llama2)
3. Включите "Расширенный режим" в настройках AI
4. Проверьте, что контекст разговора не сбит (очистите историю)

### 15. Как сбросить историю диалога с AI?
В AI-чате нажмите кнопку "Очистить историю" (иконка корзины) или перезапустите приложение.

## Кэширование и стриминг

### 16. Что такое AI кэширование?
AI кэширование сохраняет ответы на часто задаваемые вопросы локально. При повторном запросе ответ берётся из кэша мгновенно.

### 17. Как включить/выключить кэширование?
Настройки → AI → "Включить кэширование AI". По умолчанию включено.

### 18. Как очистить кэш AI?
Настройки → AI → "Очистить кэш AI" или используйте команду в терминале:
```bash
ollama rm cache
```

### 19. Что такое AI стриминг?
AI стриминг позволяет видеть ответ AI по мере генерации, а не ждать полного ответа. Первые слова появляются через <100 мс.

### 20. Как включить стриминг?
Стриминг включён по умолчанию. Если он отключён, перейдите в Настройки → AI → "Включить стриминг ответов".

## Интеграция с OpenAI

### 21. Как использовать OpenAI вместо Ollama?
1. Получите API ключ на [platform.openai.com](https://platform.openai.com)
2. В настройках Pepakura Next выберите провайдер "OpenAI"
3. Вставьте API ключ
4. Выберите модель (gpt-4, gpt-3.5-turbo)

### 22. Безопасно ли хранить API ключ OpenAI в приложении?
Да, ключ хранится локально в зашифрованном виде. Он не передаётся на наши серверы.

### 23. Сколько стоит использование OpenAI?
Зависит от модели и количества токенов. Примерно $0.002 за 1K токенов. Pepakura Next показывает примерную стоимость запроса перед отправкой.

## Расширенные вопросы

### 24. Можно ли использовать свои собственные модели Ollama?
Да, загрузите свою модель:
```bash
ollama pull my-model
```
Затем в настройках укажите её имя.

### 25. Как добавить кастомные промпты для AI?
Создайте файл `custom_prompts.json` в папке конфигурации Pepakura Next (см. путь в настройках → О программе → Пути).

### 26. Поддерживает ли AI генерацию 3D-моделей из текста?
В настоящее время AI-помощник только анализирует существующие модели и даёт советы. Генерация 3D-моделей — отдельная функция (Text-to-3D), которая находится в разработке.

### 27. Как отключить AI полностью?
Настройки → AI → "Отключить AI-функции". Все AI-кнопки станут неактивными.

## Логи и отладка

### 28. Где найти логи AI?
Логи находятся в:
- **Windows**: `%APPDATA%\com.pepakura.next\logs\ai.log`
- **macOS**: `~/Library/Logs/com.pepakura.next/ai.log`
- **Linux**: `~/.cache/com.pepakura.next/logs/ai.log`

### 29. Как сообщить об ошибке в AI?
1. Включите расширенное логирование (Настройки → AI → "Расширенное логирование")
2. Воспроизведите ошибку
3. Отправьте файл лога и описание проблемы на [GitHub Issues](https://github.com/pepakura-next/pepakura-next/issues)
