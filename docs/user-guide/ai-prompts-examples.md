# Примеры промптов для AI-помощника

## Введение

AI-помощник Pepakura Next понимает естественный язык на русском и английском. Чем конкретнее промпт, тем точнее ответ. Ниже приведены примеры промптов для различных задач.

## Категории промптов

### 1. Выбор материалов и бумаги

**Цель:** Получить рекомендации по выбору бумаги, клея, инструментов.

| Задача | Пример промпта | Ожидаемый ответ |
|--------|----------------|-----------------|
| Выбор бумаги для модели | "Какую бумагу выбрать для модели корабля длиной 30 см?" | Рекомендации по плотности (г/м²), типу бумаги (картон, ватман), брендам, советы по влагостойкости. |
| Выбор клея | "Какой клей лучше для склейки бумажных деталей?" | Сравнение ПВА, моментального клея, клея-карандаша; техники нанесения. |
| Инструменты для резки | "Какие инструменты нужны для точной резки мелких деталей?" | Рекомендации по ножам, макетным коврикам, пинцетам. |
| Печать на цветном принтере | "Как настроить принтер для печати развёрток на цветной бумаге?" | Настройки ICC-профилей, плотности чернил, калибровки. |

### 2. Оптимизация развёртки

**Цель:** Улучшить качество развёртки, уменьшить количество швов, оптимизировать раскладку.

| Задача | Пример промпта | Ожидаемый ответ |
|--------|----------------|-----------------|
| Уменьшение количества деталей | "Как уменьшить количество деталей в развёртке без потери качества?" | Советы по объединению граней, изменению параметров развёртки. |
| Оптимизация швов | "Как расположить швы на невидимых сторонах модели?" | Алгоритмы автоматического размещения швов, ручная корректировка. |
| Раскладка на листе | "Как оптимально расположить детали на листе А4 для экономии бумаги?" | Рекомендации по повороту, зеркалированию, nesting-алгоритмам. |
| Проблемы с перекрытием | "Детали перекрываются после развёртки, как исправить?" | Диагностика причин и пошаговое решение. |

### 3. Сборка и склейка

**Цель:** Получить инструкции по сборке конкретных типов моделей.

| Задача | Пример промпта | Ожидаемый ответ |
|--------|----------------|-----------------|
| Общая инструкция по сборке | "Опиши пошаговую сборку бумажной модели куба для новичка." | Последовательность склейки граней, советы по выравниванию. |
| Склейка цилиндрических деталей | "Как правильно склеить цилиндр без деформаций?" | Техники скручивания, использование оправки, контроль диаметра. |
| Сложные соединения | "Как склеить шаровые соединения в бумажной модели?" | Методы создания шаровых шарниров, усиление конструкций. |
| Внутренние рёбра жёсткости | "Нужны ли внутренние рёбра жёсткости для модели здания?" | Расчёт нагрузки, рекомендации по материалам. |

### 4. Работа с 3D-моделями

**Цель:** Подготовить 3D-модель для развёртки, исправить проблемы.

| Задача | Пример промпт | Ожидаемый ответ |
|--------|---------------|-----------------|
| Подготовка модели | "Какие параметры 3D-модели важны для качественной развёртки?" | Топология, количество полигонов, нормали, UV-развёртка. |
| Исправление не manifold-граней | "Модель имеет не manifold-грани, как исправить?" | Инструменты для автоматического исправления, ручные методы. |
| Упрощение модели | "Как упростить 3D-модель с 50k полигонов до 5k для развёртки?" | Алгоритмы ретопологии, декimation. |
| Экспорт из Blender | "Какие настройки экспорта из Blender в OBJ лучше для Pepakura?" | Параметры масштаба, ориентации осей, материалов. |

### 5. Решение проблем

**Цель:** Диагностировать и исправить ошибки в процессе работы.

| Задача | Пример промпт | Ожидаемый ответ |
|--------|---------------|-----------------|
| Развёртка не сходится | "Алгоритм MDS не сходится после 100 итераций, что делать?" | Увеличение допуска, уменьшение итераций, выбор другого алгоритма. |
| Текстуры не отображаются | "Текстуры не показываются в 2D редакторе, хотя в 3D есть." | Проверка путей текстур, форматов файлов, настроек импорта. |
| Ошибка экспорта PDF | "При экспорте PDF получаю пустой файл." | Проверка размеров страницы, настроек печати, драйверов. |
| Медленная работа AI | "AI отвечает очень медленно, как ускорить?" | Советы по кэшированию, выбору модели, аппаратному ускорению. |

## Шаблоны промптов

Используйте эти шаблоны, подставляя свои параметры:

### Для анализа модели
```
Проанализируй эту 3D-модель [описание модели] и дай рекомендации:
1. Оптимальный алгоритм развёртки
2. Ожидаемое количество деталей
3. Сложность сборки (1-10)
4. Рекомендуемая бумага
```

### Для генерации инструкций
```
Сгенерируй инструкцию по сборке для [тип модели] со следующими характеристиками:
- Количество деталей: [число]
- Уровень сложности: [новичок/средний/эксперт]
- Особые требования: [например, подвижные части]
```

### Для решения проблемы
```
У меня проблема: [описание проблемы]. Я уже попробовал: [перечисление действий]. Что делать дальше?
```

## Советы по составлению промптов

1. **Будьте конкретны:** Вместо "Как склеить?" спросите "Как склеить цилиндр диаметром 5 см из картона 200 г/м²?"
2. **Указывайте контекст:** "У меня модель корабля с 100 деталями, использую ПВА клей, бумага 180 г/м²."
3. **Задавайте структурированные вопросы:** Используйте нумерацию: "1) ... 2) ... 3) ..."
4. **Ограничивайте scope:** "Ответь в трёх пунктах" или "Дай краткий ответ".
5. **Используйте технические термины при необходимости:** AI понимает термины like "MDS", "LSCM", "non-manifold", "UV unwrap".

## Пример диалога

**Пользователь:** "У меня модель динозавра с 50 деталями. Детали мелкие, сложно склеивать. Какой клей лучше использовать и есть ли техники для упрощения сборки?"

**AI-помощник:**
1. **Клей:** Рекомендую густой ПВА с аппликатором или клей-гель. Избегайте жидких клеёв, которые деформируют бумагу.
2. **Техники сборки:**
   - Используйте пинцет с силиконовыми наконечниками.
   - Собирайте модель по секциям (голова, туловище, лапы), затем соединяйте.
   - Применяйте зубочистки для нанесения клея.
3. **Упрощение:** Рассмотрите возможность объединения мелких деталей в более крупные, если это допустимо по дизайну.

## Продвинутые промпты для экспертов

### Для разработчиков плагинов
```
Напиши код на Rust для плагина Pepakura Next, который добавляет поддержку формата [формат]. Плагин должен реализовывать trait ImportPlugin.
```

### Для исследования алгоритмов
```
Сравни алгоритмы MDS и LSCM для развёртки высокополигональных моделей. В каких случаях каждый предпочтительнее?
```

### Для интеграции с другими инструментами
```
Как настроить pipeline Blender → Pepakura Next → Cura для 3D-печати бумажных моделей?
```

## Заключение

Эти примеры помогут вам эффективно использовать AI-помощник. Экспериментируйте с формулировками и сохраняйте успешные промпты в избранное (функция "Сохранить промпт" в AI-чате).

> **Примечание:** AI-помощник постоянно обучается. Если ответ неудовлетворительный, переформулируйте вопрос или используйте кнопку "Перегенерировать ответ".
